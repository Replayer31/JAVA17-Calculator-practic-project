Yo, it's a program by Replayer!

I started learning Java 17, so this is my practice project.
I used Gemini and Claude AI for some things, but 90% of the code was written by me.

To run the program you need:

- JDK 17
- Double-click on calculator.bat

What you can already try in this program:
- 3 Calculation modes: Integer, Floating point, Double precision
- Session History: Saves your operations with timestamps
- Easy restart program, clear number or quit - Just write r/c/q! (only in operators-choose stage)
- Default operators: + or - or * or / or % (remainder of division) (I add new operators in new versions)
- And more!

Error codes:
Code 0 - Operation completed successfully!
Code 1 - Unknown error - If any error what java gonna crash
Code 2 - Data is empty - Now: If history is empty Soon: If you don't write anything and just click ENTER
Code 3 - Unknown choice - In many areas where you need to make a choice, the program already provides all the variants for you. Just copy and paste. In V4 (meaning "soon") in menu you can write a number of variant
Code 4 - Invalid response - If you wrote letters then numbers
Code 5 - Number overflow or too large - Too large number, for example biggest than integer max num
Code 6 - Division by zero - You can't divide by zero according to standard math rules
