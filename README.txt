Yo, it's a program by Replayer!

I started learning Java 17, so this is my practice project.
I used Gemini and Claude AI for some things, but 90% of the code was written by me.
To run the program you need:

- JDK 17
- Double-click on calculator.bat

What you can already try in this program:
- 4 Calculation modes: Integer, Floating point, Double precision, Unary operation
- Session History: Saves your operations with timestamps
- Easy restart program, clear number or quit - Just write m/c/q! (only in operators/unary-choose stage)
- Default operators: + or - or * or / or % (remainder of division) or p (power)
- Unary operators: v/sqrt, mod/abs, ~/r/round, s/sin, cos, t/tan, l/log, log10, e/exp
- Changelogs: View or download changelogs for versions 2, 3, and 4
- Download history: Save your current session history directly to your Downloads folder
- And more!

Error codes:
Code 0 - Operation completed successfully!
Code 1 - Error: Unknown error
Code 2 - Error: Data is empty
Code 3 - Error: Unknown choice (Tip: Choose from the variants above!)
Code 4 - Error: Invalid response
Code 5 - Error: Number overflow or too large
Code 6 - Error: Division by zero
Code 7 - Error: Unknown file operation error
